# LIST//LAB — Python Data Laboratory (10 клас)

Інтерактивний навчальний вебпрактикум з інформатики для учнів 10 класу з теми:  
**«Обробка одномірних списків даних мовою програмування Python»**.

## Можливості практикуму
- **Обов'язкова реєстрація учня** перед початком роботи (ПІБ, клас, дата виконання).
- **Теоретичний довідник** із прикладами коду, візуалізацією індексів списку та розбором 7 типових помилок.
- **9 інтерактивних практичних завдань** трьох рівнів складності (початковий, середній, високий).
- **Редактор коду у стилі Python IDLE** з нумерацією рядків, підтримкою табуляції та вертикальною консоллю **Python 3.12 Shell**.
- **Автоматична змістовна перевірка** конструкцій коду та результатів виконання.
- **12-бальна система оцінювання** кожного завдання (максимум 108 балів за 9 завдань + формула переведення у 12-бальну оцінку).
- **Автозбереження прогресу** у `localStorage` браузера та облік витраченого часу без дублювання.
- **Формування звіту** (завантаження окремого HTML-звіту зі статистикою та друк / збереження у PDF).

## Структура файлів
- `index.html` — повністю автономний односторінковий вебзастосунок (HTML + CSS + JS в одному файлі, без зовнішніх залежностей).
- `README.md` — документація проєкту та інструкція з розгортання.

## Як відкрити практикум локально
1. Завантажте файл `index.html` (або розпакуйте ZIP-архів).
2. Двічі клацніть по файлу `index.html` — він відкриється у стандартному браузері (Chrome, Edge, Firefox) без встановлення Python чи запуску локального сервера.

## Інструкція з публікації на GitHub Pages
1. Створіть новий публічний репозиторій на [GitHub](https://github.com) (наприклад, `list-lab-python-10`).
2. Завантажте у корінь репозиторію файли `index.html` та `README.md`.
3. Перейдіть у вкладку **Settings** &rarr; **Pages**.
4. У розділі **Build and deployment** оберіть джерело **Deploy from a branch**, вкажіть гілку `main` та папку `/ (root)`, натисніть **Save**.
5. Через 1–2 хвилини практикум стане доступним за постійним посиланням вигляду `https://<ваш-логін>.github.io/list-lab-python-10/`.
