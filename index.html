6.1. Поняття списку в Python

Список (list) — це впорядкована змінна структура даних у мові програмування Python, яка дозволяє зберігати цілу колекцію значень під одним іменем.

  • Для чого використовують списки: для зберігання однотипних або пов'язаних даних — наприклад, оцінок учня за семестр, показників температури за тиждень, цін товарів у кошику чи списку учасників олімпіади.
  • Чим список відрізняється від звичайної змінної: звичайна змінна зберігає лише одне значення (наприклад, mark = 11), тоді як список зберігає багато елементів одночасно у квадратних дужках [ ], розділених комами.
  • Нумерація індексів із нуля: кожен елемент списку має свій порядковий номер — індекс. Перший елемент завжди має індекс 0, другий — 1, третій — 2 і так далі.

6.2. Основні операції зі списками

Оскільки списки в Python є змінними (mutable), їх можна доповнювати, редагувати та скорочувати під час виконання програми.

Довжина, додавання, вставлення та видалення елементів

marks = [9, 10, 11] # 1. Отримання кількості елементів (довжини списку) print(len(marks)) # Виведе 3 # 2. Додавання елемента в кінець списку — append() marks.append(12) # Тепер marks = [9, 10, 11, 12] # 3. Вставлення елемента на вказану позицію — insert(індекс, значення) marks.insert(1, 8) # На позицію 1 вставляємо 8: [9, 8, 10, 11, 12] # 4. Зміна значення існуючого елемента за індексом marks[0] = 10 # Замінюємо перший елемент: [10, 8, 10, 11, 12] # 5. Видалення елемента за значенням — remove() marks.remove(8) # Видаляє першу знайдену вісімку: [10, 10, 11, 12] # 6. Видалення елемента за індексом (або останнього) — pop() last = marks.pop() # Видаляє та повертає 12; marks = [10, 10, 11]

Об'єднання списків та перевірка належності елемента

group_a = ["Олена", "Максим"] group_b = ["Ірина", "Тарас"] # Об'єднання двох списків оператором + all_students = group_a + group_b print(all_students) # ['Олена', 'Максим', 'Ірина', 'Тарас'] # Перевірка належності елемента списку оператором in if "Максим" in all_students: print("Учень є у списку!")

6.3. Обробка списків

Для опрацювання кожного елемента списку використовують цикли, вбудовані функції та розгалуження.

1. Перебирання елементів списку (за значенням та за індексами)

prices = [120, 85, 240, 150] # Спосіб А: Перебирання безпосередньо елементів for price in prices: print(price) # Спосіб Б: Перебирання за індексами через range(len(...)) for i in range(len(prices)): print("Товар", i, "коштує", prices[i])

2. Сума, максимум, мінімум та середнє арифметичне

scores = [10, 12, 8, 11, 9] total = sum(scores) # Сума всіх елементів = 50 best = max(scores) # Найбільше значення = 12 worst = min(scores) # Найменше значення = 8 average = sum(scores) / len(scores) # Середнє арифметичне = 10.0 print("Середній бал:", average)

3. Підрахунок за умовою та формування нового списку (фільтрування)

numbers = [-5, 12, 0, 8, -3, 19, 4] # Підрахунок кількості додатних чисел за допомогою лічильника count_pos = 0 for x in numbers: if x > 0: count_pos += 1 print("Кількість додатних:", count_pos) # Виведе 4 # Формування нового списку з парних чисел even_numbers = [] # Крок 1: створюємо порожній список for x in numbers: # Крок 2: перебираємо елементи if x % 2 == 0: # Крок 3: перевіряємо умову парності even_numbers.append(x) # Крок 4: додаємо у новий список print("Парні числа:", even_numbers) # [12, 0, 8, 4]

6.4. Типові помилки під час роботи зі списками

1. Неправильне використання індексів (плутанина між 1-м та 0-м елементом) Учні часто пишуть nums[1], щоб отримати перший елемент, хоча перший елемент має індекс nums[0].
2. Вихід за межі списку (IndexError: list index out of range) Якщо у списку 5 елементів, то їхні індекси: 0, 1, 2, 3, 4. Звернення до nums[5] спричинить помилку виходу за межі діапазону.
3. Неправильні відступи (IndentationError) Тіло циклу for та блоку if у Python обов'язково виділяється відступом у 4 пробіли. Якщо рядок print(...) чи result.append(...) записано без відступу, він виконається лише один раз після циклу, а не для кожного елемента.
4. Помилки в назвах змінних (NameError) Звернення до змінної number замість оголошеного списку numbers або використання змінної циклу з іншою назвою.
5. Неправильне використання циклу for Написання for x in len(nums): замість for x in nums: або for i in range(len(nums)):. Число не можна перебирати без range().
6. Помилки під час роботи з умовами Використання одного знака присвоєння = замість порівняння == (наприклад, if x % 2 = 0: замість if x % 2 == 0:) або пропуск двокрапки : наприкінці заголовка.
7. Неправильне застосування методів списків Метод append() змінює список на місці і повертає None. Не можна писати nums = nums.append(5) — правильно писати просто nums.append(5).
